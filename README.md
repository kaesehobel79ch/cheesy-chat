# `Cheesy Chat`

Twitch-Chatbot mit lokaler KI. `Cheesy Chat` beantwortet Fragen im eigenen Twitch-Chat, schreibt Sperren mit und hält fest, was während einer Sendung war. Die KI läuft auf dem eigenen Rechner; jede Antwort ist im Chat mit „[KI-Bot]“ gekennzeichnet.

**[Herunterladen (neueste Version)](https://github.com/kaesehobel79ch/cheesy-chat/releases/latest)**

Kostenlos (Freeware) von Käse_Hobel – [info-kaesehobel.ch](https://www.info-kaesehobel.ch/). Oberfläche deutsch und englisch.

## Installieren

1. Unter „Herunterladen“ die Datei `CheesyChat_<Version>.zip` laden.
2. ZIP entpacken.
3. `CheesyChat_<Version>_Setup.exe` starten und den Schritten folgen. Die KI-Modelldatei (rund 2,4 GB) lädt das Setup selbst herunter.

Alles Weitere steht im Programm unter „Info“ – „Unterlagen“ (Handbuch, Datenschutz, Lizenzen).

## Was der Bot kann

- Fragen im Chat beantworten (`!?`, `!ai` oder den Bot direkt ansprechen), bei Bedarf mit Websuche
- Eingebautes Grundwissen aus Wikipedia, mit Quellenangabe in jeder Antwort
- Chatspiele Käserollen und Bananen-Weitwurf mit Bestenliste
- Spielkategorie, Kurzinfo zum Spiel, Fallout-76-Atomcodes
- Sperren mitschreiben, damit sich ein Verstoss beim Twitch-Support belegen lässt
- Chat-Fenster mit Namensfarben und Abzeichen, eigene Chat-Befehle

`Cheesy Chat` ist kein Moderationsbot. Er sperrt niemanden, macht keine Werbung und legt keine Profile über einzelne Zuschauer an.

## Voraussetzungen

- Windows 10 ab Version 1809 oder Windows 11, 64 Bit
- Administratorrechte für die Installation, rund 2,7 GB freier Platz
- Arbeitsspeicher mindestens 16 GB, angenehm sind 32 GB
- Eine Grafikkarte ist nicht nötig, wird aber genutzt, wenn vorhanden
- .NET muss nicht installiert sein, die Laufzeit ist im Programm enthalten

Das Programm ist nicht digital signiert. Beim Starten des Setups meldet Windows deshalb „Der Computer wurde durch Windows geschützt“. Das ist ein Fehlalarm.
